# Film Arama Uygulaması

Bu proje, OMDb API kullanılarak geliştirilmiş basit bir film arama uygulamasıdır.

## Özellikler
- Film adına göre arama yapma
- Film başlığı, yıl, tür, yönetmen ve afiş bilgilerini gösterme
- Hata mesajı gösterme
- Son aramayı localStorage ile saklama
- Responsive tasarım

## Kullanılan Teknolojiler
- HTML
- CSS
- JavaScript
- OMDb API
